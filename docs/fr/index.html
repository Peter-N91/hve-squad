hve-squad

hve-squad réunit les agents, prompts, instructions et skills HVE Core dans un seul ensemble installable et fournit un Squad Coordinator qui répartit votre demande entre plusieurs agents en parallèle. Utilisez le package APM complet dans VS Code, ou la paire de plugins dans Copilot CLI et App.

Référence

Ce que fait ce projet

Ce dépôt fournit un package APM dont le contenu est sélectionné et qui référence les ressources de microsoft/hve-core dans .github/agents, .github/instructions, .github/prompts et .github/skills. Au lieu de maintenir manuellement des centaines de chemins de dépendances, un script d'automatisation régénère leur liste dans apm.yml.

📦

Un seul ensemble

Détecte automatiquement les artefacts Markdown pris en charge dans les dossiers HVE Core sélectionnés et les distribue ensemble.

♻️

Reproductible

Les dépendances sont résolues dans apm.lock.yaml pour rendre les installations reproductibles.

🧩

Squad incluse

Un Squad Coordinator créé localement, accompagné d'agents de soutien, d'instructions, d'un prompt et d'un skill.

☁️

Couche d'exécution Azure

Architecture, IaC, déploiement, documentation de l'infrastructure après déploiement et triage des ressources — le tout depuis la squad. Les déploiements restent soumis à une validation humaine et la nouvelle capacité Azure MCP permet d'explorer la gouvernance en direct.

🔁

Modernisation

Un rôle de la squad qui planifie les mises à niveau des frameworks et des dépendances ainsi que les migrations entre piles technologiques, puis confie l'exécution au rôle développeur ou aux outils officiels App Modernization.

🗂️

Fédération

Faites fonctionner plusieurs sous-squads nommées dans un même dépôt — une squad product pour l'équipe métier, une squad azure pour les architectes — chacune étant une squad ordinaire avec sa propre racine d'état, aiguillée par /squad-federation. Une fonctionnalité facultative qui s'ajoute à l'existant.

💡

Étape de découverte

Lorsqu'une exécution démarre sans aucun document écrit, la squad propose une séance d'idéation avant de construire — cadrage, options et bref document de synthèse que le contrôle d'entrée valide ensuite. Cette étape est proposée, et non automatique, car les idées doivent venir de vous, pas du modèle. Incluse dans les profils product et full.

✅

Contrôle d'entrée des exigences

Avant de planifier ou de construire à partir d'un PRD, d'un BRD, d'une spécification ou d'une autre entrée, la squad en vérifie l'exhaustivité et la clarté, consigne un verdict de préparation et corrige automatiquement les lacunes bloquantes avant de poursuivre. Inclus dans les profils product et full.

Projets compagnons

Au-delà de l'expérience locale /squad, la squad est accessible dans deux autres hôtes grâce à des dépôts compagnons. Aucun n'est un fork — tous deux sont construits à partir d'une version étiquetée de hve-squad, de sorte que chaque version correspond à une version connue de ce package. Consultez Écosystème pour savoir lequel choisir.

🔌

Serveur MCP

hve-squad-mcp expose la squad sous forme d'outils invocables par un modèle — squad_research, squad_plan, squad_review, squad_architect, squad_run et un outil déterministe de production de fichiers squad_render_pptx — via Streamable HTTP avec authentification Entra, pour permettre à des hôtes tels que Copilot Studio d'appeler la squad.

MCP
🧩

Plugin Copilot CLI

hve-squad-plugin est un miroir généré de l'arborescence du plugin de la squad, publié uniquement lors des sorties de versions, sous forme de marketplace de plugins Copilot. Il exécute la squad dans GitHub Copilot CLI et dans l'application de bureau sans apm install.

Installation rapide

# APM CLI must report 0.29.0:
apm --version
# In the project you want the squad in:
apm install "Peter-N91/hve-squad#vX.Y.z" --target copilot

APM 0.29.1 et 0.30.0 présentent une régression qui empêche l'installation des dépendances de ce package. Utilisez APM CLI 0.29.0 jusqu'à la résolution du problème. Appelez ensuite le coordinateur depuis Copilot Chat avec le prompt /squad. Consultez Bien démarrer pour les commandes d'installation à version épinglée sous Windows et macOS et pour la procédure complète.
