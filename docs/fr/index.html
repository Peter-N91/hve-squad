hve-squad

hve-squad installe un plugin autonome unique pour VS Code, Copilot CLI et l'application Copilot. Il inclut l'équipe HVE Core épinglée avec les agents, skills, règles et hooks Squad, tandis qu'APM reste disponible lorsque les mêmes personnalisations doivent être copiées dans un dépôt.

Ce que fait ce projet

Ce dépôt publie un plugin Copilot unique contenant la squad et chaque composant déclaré par le commit exact de microsoft/hve-core épinglé dans apm.yml. Le même manifeste continue d'alimenter la solution de repli APM. L'automatisation régénère la liste des dépendances et les branches du plugin publiées manuellement.

📦

Un seul ensemble

Installe Squad et son équipe HVE Core validée depuis une seule racine et une seule version de plugin.

♻️

Reproductible

Le plugin consigne son commit HVE Core ; la solution de repli APM résout les dépendances dans apm.lock.yaml.

🧩

Squad incluse

Un Squad Coordinator créé localement, accompagné d'agents de soutien, d'instructions, d'un prompt et d'un skill.

☁️

Couche d'exécution Azure

Architecture, IaC, déploiement, documentation de l'infrastructure après déploiement et triage des ressources — le tout depuis la squad. Les déploiements restent soumis à une validation humaine et la nouvelle capacité Azure MCP permet d'explorer la gouvernance en direct.

🔁

Modernisation

Un rôle de la squad qui planifie les mises à niveau des frameworks et des dépendances ainsi que les migrations entre piles technologiques, puis confie l'exécution au rôle développeur ou aux outils officiels App Modernization.

🗂️

Fédération

Faites fonctionner plusieurs sous-squads nommées dans un même dépôt — une squad product pour l'équipe métier, une squad azure pour les architectes — chacune étant une squad ordinaire avec sa propre racine d'état, aiguillée par le Squad Federation Coordinator. Une fonctionnalité facultative qui s'ajoute à l'existant.

💡

Étape de découverte

Lorsqu'une exécution démarre sans aucun document écrit, la squad propose une séance d'idéation avant de construire — cadrage, options et bref document de synthèse que le contrôle d'entrée valide ensuite. Cette étape est proposée, et non automatique, car les idées doivent venir de vous, pas du modèle. Incluse dans les profils product et full.

✅

Contrôle d'entrée des exigences

Avant de planifier ou de construire à partir d'un PRD, d'un BRD, d'une spécification ou d'une autre entrée, la squad en vérifie l'exhaustivité et la clarté, consigne un verdict de préparation et corrige automatiquement les lacunes bloquantes avant de poursuivre. Inclus dans les profils product et full.

Distribution et hôtes compagnons

Le plugin Copilot principal est publié depuis ce dépôt. MCP et Microsoft Agent Framework restent des intégrations d'hôte séparées. Consultez Écosystème pour savoir laquelle choisir.

🔌

Serveur MCP

hve-squad-mcp expose la squad sous forme d'outils invocables par un modèle — squad_research, squad_plan, squad_review, squad_architect, squad_run et un outil déterministe de production de fichiers squad_render_pptx — via Streamable HTTP avec authentification Entra, pour permettre à des hôtes tels que Copilot Studio d'appeler la squad.

Installation rapide

copilot plugin marketplace add Peter-N91/hve-squad#plugin
copilot plugin install hve-squad@hve-squad

Dans VS Code ou l'application Copilot, ajoutez le même marketplace depuis l'interface de personnalisation des plugins. Sélectionnez ensuite Squad Coordinator. Consultez Bien démarrer pour les mises à jour, l'installation preview et la solution de repli APM dans un dépôt.
