Dépannage

Une méthode commune

Chaque profil comprend les rôles de recherche, planification, implémentation, revue et tenue de l'historique. Les spécialistes complètent cette base selon votre objectif : produit, architecture, sécurité, accessibilité, exploitation ou Azure.

Le package rassemble les agents, prompts, instructions et skills de Microsoft HVE Core avec les sources de la squad. APM les installe dans le dossier .github/ de votre dépôt ; les plugins proposent un autre accès dans CLI et App, avec des limites de couverture à vérifier.

Le profil product aide à cadrer un besoin, formaliser les exigences et préparer un backlog. Le profil azure ajoute architecture, IaC, déploiement soumis à approbation, documentation de l'existant et diagnostic en lecture seule. Une fédération permet à plusieurs sous-squads de conserver leurs propres livrables et historiques.

Vous restez responsable des décisions. Autopilot ne supprime ni les validations humaines ni les limites du périmètre demandé. Un livrable généré n'est pas nécessairement testé, déployé ou validé.

Ateliers pratiques

Atelier onepoint : cadrer puis commencer un complément Office, avec un parcours bilingue. Atelier Qubix : du besoin métier au backlog, à la fédération et à l'implémentation.

Travaillez dans votre propre dépôt. Placez uniquement des documents autorisés dans knowledge-docs/ et n'insérez aucun secret dans vos demandes.
