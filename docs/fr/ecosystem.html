Écosystème

Une source commune, trois distributions. Choisissez l'accès adapté à votre environnement sans confondre leurs capacités d'exécution.

Les trois dépôts

DépôtRôleUsage
hve-squadSources de la squad dans squad-src/ et package APM.Installer le contenu complet dans votre dépôt pour VS Code.
hve-squad-pluginDistribution générée depuis un tag publié ; marketplace de plugins.Utiliser les agents dans Copilot CLI ou App.
hve-squad-mcpServeur Model Context Protocol exposant les intentions de la squad comme outils.Intégration à un hôte MCP, notamment Copilot Studio selon le mode.

Les distributions dérivées ne sont pas des forks indépendants. Elles sont construites à partir d'une version identifiée de hve-squad ; leurs limites restent toutefois propres à chaque hôte.

Package APM

Choisissez cette voie pour utiliser /squad dans Copilot Chat avec les ressources installées dans le dépôt. Les versions publiées sont épinglées ; une installation sans référence suit la branche par défaut. Voir l'installation VS Code.

Plugins CLI et App

Le marketplace publie deux entrées à installer ensemble :

copilot plugin marketplace add Peter-N91/hve-squad-plugin
copilot plugin install hve-squad@hve-squad-plugin
copilot plugin install hve-squad-hve-core@hve-squad-plugin

Sélectionnez ensuite l'agent Squad Coordinator. Les prompts VS Code ne sont pas lus par ces hôtes. Un skill nommé squad n'est pas une invocation du coordinateur.

Deux règles de mise à jour : réinstallez hve-squad-hve-core lorsque son commit épinglé change, et n'installez pas le plugin officiel hve-core à côté. Vérifiez le COPILOT_HOME réellement utilisé par chaque client.

La distribution plugin peut manquer de domaines HVE Core. Faites vérifier les capacités par squad-doctor ; la solution documentée pour les domaines absents est l'installation du package HVE Core complet dans le dépôt.

Guides de la distribution, en anglais : CLI, application de bureau, notes VS Code et distribution en entreprise.

Serveur MCP

Les outils principaux sont squad_research, squad_plan, squad_review, squad_architect, squad_run, squad_federate et squad_render_pptx. Leurs entrées reprennent les intentions et paramètres de la squad.

  • Mode délégué, stdio : VS Code délègue aux vrais agents installés. Leur installation reste nécessaire.
  • Mode distant embarqué, Streamable HTTP avec Entra : accès à des réponses et livrables textuels sous authentification, isolation et plafonds. Le périmètre est consultatif, pas une exécution de code ou un déploiement distant.

Consultez les capacités actuelles dans la documentation MCP (anglais) avant de concevoir une intégration. Un outil nommé « run » n'est pas à lui seul une garantie d'exécution sur l'hôte distant.

Alignement des versions

Le script scripts/Build-SquadPlugin.ps1 extrait les sources d'un tag immuable lors d'une publication. Le contenu généré ne doit pas être modifié à la main dans le dépôt de distribution. Le tag source permet de relier une version du plugin ou du serveur à la version du package.
