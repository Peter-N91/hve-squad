- **The governance report could not show what a run consumed, what the same work would have cost without HVE Squad, or what that spend bought (#164).** `/squad-governance-report` now runs the deterministic renderer `squad-src/.github/skills/squad/scripts/New-SquadGovernanceReport.ps1` (with the `SquadGovernanceReport.*` modules beside it). It reads squad state read-only and writes the same seven sections plus the complete `consumption.md`: Attribution, Usage & Cost, Derivation, Unit Economics, Cost Comparison, and the legacy Observed Usage. Cost, tokens, and ROI carry their basis (`exact-native`, `estimated`, `modeled`, `host-billed`) and bases are never added together. Avoided cost, cost reduction, ROI, and the cost multiple come from the ledger's own with and without HVE Squad figures and are labeled a modeled counterfactual; a run that cost more than its baseline is shown as negative, not as a saving.
- **The report now argues the case for HVE Squad from evidence, not assertion.** Two panels, "what this run spent" and "what this run produced", list claims computed from the run's records (lower spend, measured spend, right-sized models, a cost ceiling, independent review, council and intake gates, human gates, deliverables with evidence) and mark each shown, not shown, or unavailable.
- **The report follows the ledger instead of being adapted to it.** The ledger is mirrored section by section, so a section or column added to `consumption.md` later appears with no change to the renderer. Only the headline figures are recognized by header text, and they read "not derivable" when a header is not recognized. Unknown or unresolved models and their fallback prices, `tier-default` rows, stale Basis notes, mismatched totals, mixed bases, shared whole-session totals, and shared native request identities are reported as data-quality notes without repairing the ledger. Federation reports show each sub-squad's ledger and count a shared host session once.
- **`period=7d` and `period=30d` no longer imply that ledger totals are period-specific.** The window is the N calendar days ending on the as-of date; dated entries are filtered, and the cumulative ledger figures are labeled as whole-run.
- **The output is reproducible and safe to share.** The same state files and `-AsOf` date give a byte-identical, self-contained HTML file, written atomically to a local path outside the squad state tree, with a JSON receipt (path, summary with ROI, basis, grounding, gaps, data quality). `squad-src/.github/agents/squad/squad-governance-report.agent.md` runs the script first and keeps the manual steps as its fallback, and `tests/tier0/GovernanceReport.Tests.ps1` asserts on the rendered output.
