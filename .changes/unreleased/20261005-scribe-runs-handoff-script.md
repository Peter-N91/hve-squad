- **Scripted ordinary hand-off under `routing=economy` (economy-only; `off`, `ranked`, and `manual` keep the v0.18.0 Scribe procedure byte for byte).** Under economy the coordinator adds `"handoff": "script"` to an ordinary payload (history, decision, orchestration, state advance), and the Squad Scribe, still the single writer, runs the new `scripts/Write-SquadHandoff.ps1` on it as its first action. The script validates a closed-key JSON payload before writing, appends the `entry-schemas.md` shapes, advances `state.json`, runs the ledger `-Write`, and exits 0 only when `-Check -ExpectedHistoryCounts` passes. It refuses with exit 7 unless `team.md` records `Model routing: economy`, holds an exclusive per-root lock (exit 8 on timeout; a crashed holder releases it), and on failure restores only files still holding the bytes it wrote. Anything outside its scope (a cost ceiling, a federation root, an unrostered agent, secret-like text, a replay) goes back to the Scribe's own procedure with exit 2. `references/economy-mode.md` documents the payload with a complete example that a Tier 0 test feeds to the script, and an economy-only `## Intake Waiver` decision that lets an unattended run continue without an intake verdict only when it is recorded and named in the final synthesis. The Scribe's hot core gains one Cold-File Dispatch Table row and stays within its byte budget. `tests/tier1/benchmark/scribe-writer-ab-2026-10-05.md` compares who runs the script (about 16% fewer credits when the Scribe does, no consistent time difference); it is not a speed claim for the script.
