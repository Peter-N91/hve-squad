- **Scripted ordinary hand-off under `routing=economy` (applies only under `routing=economy`; `off`, `ranked`, and `manual` keep the v0.18.1 Scribe procedure byte for byte).** Under economy the coordinator adds `"handoff": "script"` to an ordinary payload (history, decision, orchestration, state advance), and the Squad Scribe, still the single writer, reads only the new Scribe-only `references/economy-scribe.md` (under 3 KB) and runs the new `scripts/Write-SquadHandoff.ps1` on it as its first action; it reads its full hot core only on fallback, so an economy hand-off reads about 2.7 KB instead of about 80 KB plus `economy-mode.md`. The script validates a closed-key JSON payload before writing, appends the `entry-schemas.md` shapes, advances `state.json`, runs the ledger `-Write`, and keeps the writes when `-Check -ExpectedHistoryCounts` passes or reports only a v0.18.1 `ledger-only` mismatch (printed as `WARN ledger-only:`); a `history-integrity` failure, a missing failure class, or a crash rolls back with exit 3. It refuses with exit 7 unless `team.md` records `Model routing: economy`, holds an exclusive per-root lock keyed by the canonical root (8.3 short names, junctions, and links resolve to one lock; exit 8 on timeout; a crashed holder releases it), reads every state-dependent value after the lock, and lands two ordinary hand-offs started at once one after the other (a deliverable is credited once, exit 1 otherwise), warns without refusing when the `## Economy Mode Accepted` decision is missing or a record lacks its `Route: economy` or `Route: bounded` marker (it adds the marker), and on failure restores only files still holding the bytes it wrote. Anything outside its scope (a cost ceiling, a federation root, an unrostered agent, secret-like text, a replay) goes back to the Scribe's own procedure with exit 2. `references/economy-mode.md` documents the payload with a complete example that a Tier 0 test feeds to the script, and an economy-only `## Intake Waiver` decision that lets an unattended run continue without an intake verdict only when it is recorded and named in the final synthesis. The Scribe agent gains one exception line and its hot core one Cold-File Dispatch Table row, and stays within its byte budget. `tests/tier1/benchmark/scribe-writer-ab-2026-10-05.md` compares who runs the script (about 16% fewer credits when the Scribe does, no consistent time difference); it is not a speed claim for the script.
