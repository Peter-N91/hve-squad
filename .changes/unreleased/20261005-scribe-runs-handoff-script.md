- **A model-driven Scribe spent 358 s and 40 credits transcribing one ordinary hand-off in a live bounded-lane run.** An ordinary hand-off (history, decision, orchestration, state advance) is now written by the new `scripts/Write-SquadHandoff.ps1` from a JSON payload, run by the Squad Scribe as its first action before it loads any reference; the coordinator sends the payload with the exact command line and never runs the script itself, so the Scribe stays the single writer. The script validates before writing, appends the `entry-schemas.md` shapes, advances `state.json`, runs the ledger `-Write`, exits 0 only when `-Check -ExpectedHistoryCounts` passes, restores every touched file on failure, and sends anything it does not cover (a cost ceiling, a Cost Preflight ref or slot, a federation root, an unrostered agent, secret-like text, a replay) back to the Scribe's own procedure with exit 2. It derives `priced_as` from the model's rate row (a supplied mismatch is corrected with a `WARN`), strips backticks from text fields, and records a missing `cli-pinned` `passedModel` as the pinned model, so common payload slips no longer cost a refusal round-trip. In a 3-pair live comparison against the coordinator running the script, the Scribe path cost about 16% fewer credits (median 59.3 vs 70.3) at a median 6 s longer, with identical quality (10/10 hidden tests, 2/2 mutants, ledger check passing in all six runs); see `tests/tier1/benchmark/scribe-writer-ab-2026-10-05.md`.
