- **Ranked, Economy, and Manual routing no longer treat `sessionModel: auto` as the host model inventory.** Copilot CLI and app plans must pass the exact model enum advertised by the `task` tool; unresolved or unpriced session metadata now yields no automatic suggestion and fails before any `team.md` Model cell is changed. Concrete priced session models retain the documented unverified VS Code-only cost-ceiling fallback.
- **Resolved routes now control the native dispatch.** The coordinator copies each non-empty planned model into the `task` or `runSubagent` `model` argument, so an agent's frontmatter pin can no longer silently replace the Ranked, Economy, or Manual selection.
- **Exact native consumption now accumulates across Copilot sessions.** The ledger writer keeps one human-readable `consumption.md` and a lazy, closed-schema `consumption-sessions.json` journal that upserts each native session, rejects duplicate accounting identities or history-prefix drift, and commits with `state.json` and the ledger as one transaction. If a run already spans sessions before the journal exists, `-SessionLog auto` can bootstrap it from complete, uniquely matching repository-session windows; the selected active session tolerates the bounded host tool-completion tail, and the next session refreshes that snapshot from its completed log before appending. Ambiguous coverage still falls back to estimates. Journal timestamp parsing is culture-independent so content digests remain stable on replay. Existing single-session exact ledgers migrate without resetting historical totals.
- **APM and plugin agent identities now reconcile identically.** Exact attribution canonicalizes raw host names, display names, and unique namespace/path suffixes against the history-backed agent set, so `Squad Lead` and `hve-squad:squad-lead` produce the same role row for every dispatched agent while ambiguous aliases still fail closed.
- **Third and later exact sessions no longer serialize empty history suffixes as `[null]`.** The writer emits canonical empty arrays, digest-valid journals created by the affected local build are normalized safely, and federation promotion explicitly preserves and verifies the optional exact-session journal with the adopted member.
