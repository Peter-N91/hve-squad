- **Background workstreams under `routing=economy` (applies only under `routing=economy`, interactive mode, Copilot CLI; `delivery=background` is ignored under `off`, `ranked`, and `manual`, which keep v0.18.1 behavior, and the `/squad` prompt says so).** Under economy, independent workstreams with disjoint write sets run as background subagents under one confirmation while the coordinator keeps talking to the user. Coordinator-only gates run in the foreground first, and only a bounded workstream or one with a confirmed plan launches. A `## Background Workstreams Launched` decision is recorded before launch and a `## Background Workstreams Agents` decision maps each workstream to its agent id right after. A resumed session recovers from disk first: each listed workstream with no hand-off yet is verified on disk (deliverables newer than `launchedAt`, `Status: complete` change records, a review verdict) and recorded, or reported as not delivered with its partial files; `read_agent` is used only for agent ids recorded in the current session, and nothing is relaunched silently. The coordinator dispatches a bounded workstream's owners and named reviewer directly; only a multi-stage workstream uses the new non-user-invocable `Squad Workstream Lead`, which carries the Squad Lead's pin and no `tools:` list, copies each owner's `Model` cell, picks no model, and writes no squad state. Each workstream is verified on disk and handed to the Squad Scribe, which runs `Write-SquadHandoff.ps1`; its per-root lock writes concurrent hand-offs one after the other, and a Tier 0 test starts two at once on one root and checks both land and the ledger check passes. The script accepts an optional `workstream` id (with `launchedAt` and `since`), requires a review-class record for it, refuses a deliverable already credited and not modified since, and records the lead's own turns from `orchestration.leadConsumption`. VS Code has no background `task`, so there the same workstreams run one at a time in the foreground. `Get-SquadDispatchBrief.ps1 -Background` embeds the procedure. The coordinator's only change is the lead in its `agents:` list, and a Tier 0 test keeps the lead out of every other file a default run reads; the procedure lives in `references/economy-mode.md`. A live background run on the Copilot CLI is still required before this is released.
