HVE SQUAD DOCUMENTATION

The main documentation site shares the Eleventy/Pagefind foundation, blue/cyan/
green identity and fonts already adopted by the plugin documentation. MCP and MAF
share the shell with their distinct product palettes.

Local development (Node.js 22+)
  npm ci
  npm run docs:test
  npm run docs:build
  npm run docs:dev

Port 4176 is the main-site development preview. Pagefind indexes refresh during
docs:build; restart docs:dev after content edits to refresh search. Pull requests
build/validate, while only main can deploy through the Pages workflow.

Original English content stays in docs/*.html; complete French equivalents are
in docs/fr/*.html. The original source chrome remains readable but is not the
deployed template. Eleventy extracts the hero, demo selector, main body and footer
without rewriting technical prose or examples. Code comments and prompt strings
remain exact in translations; instructions outside copyable blocks are localized.
The archival governance report is copied unchanged, not treated as a new guide.

Reader behavior
System/Light/Dark persists using hve-docs-theme, shared with sibling sites.
Existing scoutTheme and host query overrides are retained. The host selection is
synchronized across local tabs and persisted with hve-docs-host. VS Code examples
retain exact original slash commands; CLI and App show agent-selection guidance
outside copyable request arguments. Language changes keep page, section and query.
Without JavaScript all static content and manual host panels remain readable.
Diagrams show their source if rendering is unavailable, and can zoom to full size.

Additional languages
Add a BCP 47 key, native name, one-segment prefix, ltr/rtl direction and every UI/
page label to site/locales.json. Add its host UI messages to host-locales.json.
Translate every guide, keeping heading order, existing IDs, links and code.
Translate diagram labels in diagram-locales.mjs; never change graph topology.
Builds reject missing files, headings, UI keys or diagram translations.

Publication boundaries
Only the named public pages/assets, videos, existing public templates and archival
governance report are copied. docs/planning, docs/architecture, knowledge-docs and
.copilot-tracking are not published. Generated _site is ignored and rebuilt cleanly.
No changes to squad-src, APM pins, package release logic or runtime agents are needed.

Newsletter
site/_includes/footer-extra.njk is the reserved component extension. It currently
renders nothing: no fake signup, disabled CTA, tracking or email collection.
Before activating subscriptions, choose the provider/backend, data controller,
consent/privacy wording, double-opt-in/unsubscribe policy and real success/error
handling. Public deployment or external subscriber-data transfers require approval.
